# Sales Data Analysis

A simple Python project for analyzing sales data, visualizing trends, and summarizing key business metrics.

## Features
- Load sales data from CSV
- Calculate revenue, profit, and unit sales summaries
- Identify top-performing products and regions
- Visualize monthly sales trends
- Export a summary report and charts

## Project structure
- `data/` – sample sales dataset
- `src/` – Python scripts for analysis
- `output/` – generated charts and summary reports

## Setup
```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## Run the project
```bash
.venv\Scripts\python src\main.py
```

## Output files
- `output/sales_dashboard.png`
- `output/sales_summary.txt`
